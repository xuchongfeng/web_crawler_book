# 书籍目录规格（确认稿 v3）

**日期：** 2026-08-23  
**状态：** 已由作者确认，作为内容写作的目录初稿  
**读者页：** `docs/outline.md`

## 1. 目标与权重

面向有一定基础的开发者。新手走完整路线；资深读者把第 3 章当自检，从第二部分进入。

- 基础（第一部分第 3 章及以前，不含第 2 章地图）：约 15–20%
- 进阶（第二部分起）：约 80%
- 不复刻崔庆才工具百科，不复刻 Mitchell 通识长文

## 2. 结构

九个部分 + 附录，章号 1–26，与 `docs/outline.md` 逐节一致。第 2 章只做难点地图，细节在后续各部分展开；第 2.8 节必须做「难点 → 部分/章」跳转表。

## 3. 写作边界（全书约束）

只写授权环境、自有 / Demo / 合作测试包、公开或合作数据。

**不写：**

- 商业加固脱壳步骤、内存 dump、unpinning、绕过反调试
- 用 Frida / unidbg 从第三方 so 提取密钥或签名
- 接码、海外号源获取、养号节奏、对第三方批量注册
- 打码平台打线上业务、未授权群控刷量
- 伪造 TLS/浏览器指纹以过 WAF 的操作序列

第 8 章、第 14.5 节、附录 E 必须重申上述边界。第 7 章账号池仅含作者拥有或授权的测试号。

- 《Python3网络爬虫开发实战（第2版）》崔庆才：工具与国内实战百科；本书不按 17 章重写。
- 《Python网络爬虫权威指南（第2版）》Mitchell：模型与伦理；本书不把 NLP、用爬虫测网站作为主线。

对照表放附录 C。
