# 第 4 章 出口类型与任务匹配

从这一章起进入第二部分。第 3 章的脚本默认从你本机的公网 IP 出去；一离开 Demo，站点看到的「你是谁」往往先取决于**出口**——流量最后一跳的地址和它所在的网络。

本章只解决选型：哪种出口配哪种任务。池怎么建、分数怎么打、如何和浏览器 Context 绑定，留给第 5 章。伪造 TLS / 浏览器画像去过 WAF，本书不写（第 1.5 节）。

仍先问第 1.3 节：官方 API 或合作导出够用时，不要为了「换 IP」上出口。打自己的 Demo，直连即可。

## 4.1 机房 / 住宅 / 移动 / ISP

业界常把出口按**地址从哪来**分成四类。名字是供应商话术，选型看的是：ASN 像不像数据中心、地址稳不稳、贵不贵、合不合法。

**机房（数据中心）。** 云主机、机柜里的固定或池化 IP。便宜、快、好自动化。对方若按 ASN 或已知云段过滤，这类出口最容易被当成自动化流量。适合：你自己的靶场、开放数据、明确允许机房访问的接口、内部联调。

**住宅。** 落在消费级宽带地址段上的出口。部分站点对这类地址更宽容，单价通常明显高于机房。关键问题不是「好不好使」，而是**地址从哪来**：你自己的宽带、合同清楚的供应商，和来路不明的「海量住宅网」，法律与声誉完全不同。后者不在本书采购清单里。

**移动。** 经运营商蜂窝网出去，常有 CGNAT，地址会变，贵。部分 App 或短信场景会把「移动网」当作一种环境信号。适合少量、必须贴近手机网络的授权测试，不适合当默认爬虫出口。

**ISP / 静态住宅。** 运营商地址段上相对稳定的 IP，介于机房和轮换住宅之间：比机房「像人」，比轮换住宅更好做粘性会话。适合要连续登录、又希望出口别一天一变的授权任务。贵，要算清「每条会话绑多久」。

没有绝对最好的一类。把任务写成：「要不要保持同一身份」「对方是否歧视机房 ASN」「预算多少」，再对表，而不是先买最大的池。

## 4.2 轮换与粘性会话

同一类地址，还有**换不换、多久换一次**。

**轮换：** 几乎每个请求（或每很短一段时间）换一个出口。适合彼此独立、不依赖登录态的只读拉取，例如开放目录里互不相关的页面。不适合：登录后翻页、购物车、App 里同一 Token 的连续调用——出口一换，对方便可能认为会话被盗或评分骤降（第 2.3 节）。

**粘性：** 在一段窗口内（几分钟到几十分钟，或整次任务）固定同一出口。登录 Cookie、`httpx.Client`、Playwright 的 `BrowserContext`、App 会话，都应和这条出口一起申请、一起释放。[第 5 章](ch05-proxy-pool.md)的 `acquire` 会按「任务要粘性多久」发货。

**任务匹配（先记这张表）：**

| 任务 | 更稳的出口策略 |
|------|----------------|
| 自建 Demo / 官方 API | 直连，不必上代理 |
| 互不相关的公开页、无登录 | 机房或廉价轮换往往够 |
| 同一账号连续多步 | 粘性；出口与 Cookie/Token 同生共死 |
| 浏览器自动化 | 一个 Context 一条粘性出口 |
| 真机 / 云手机 | 设备级出口或该设备上的固定代理，见第 19 章 |
| 对方明确拒绝机房 ASN | 先确认你有权采集；再考虑 ISP/住宅，而不是上对抗 |

「换得越勤越不容易封」只在**无会话**时偶尔成立；有会话时，乱轮换本身就是风险信号。

## 4.3 地域、ASN、协议

选出口时，除了「像不像机房」，还要看三件小事。

**地域。** 广告、价格、本地生活、牌照内容常按国家或城市分流。出口地域应和任务声明的市场一致，否则你看到的根本不是目标数据。不要为了「看起来更像当地人」去买无法说明来源的住宅网。

**ASN。** 自治域编号能粗分：云厂商、家宽运营商、移动网。对方的名单往往针对 ASN 或网段，而不是你的 User-Agent。采购时让供应商提供网段/ASN 说明，便于你自己做健康检查（第 5 章）。

**协议与认证。**

- `HTTP` 代理：浏览器和 `httpx` 都熟；HTTPS 目标走 CONNECT。
- `SOCKS5`：部分客户端、部分隧道更方便；确认库是否真的走了代理，而不是静默直连。
- 认证：用户名密码 vs 出口白名单。白名单适合固定工作者 IP；密码适合动态扩容，密钥按[第 7.9 节](ch07-accounts.md)一类习惯保管。
- IPv6：有的池只有 v4。双栈目标可能让你以为「通了」其实走了另一条路径，排障时把协议版本记进日志。

这些参数要写进任务配置，不要散落在每个人的环境变量里。

## 4.4 自建与采购的成本、合规

**先算要不要买。** 自有 Demo、内网服务、开放 API，出口成本应为零。为练习代理而打公共网站，既贵也容易踩第 1.3 节。

**自建。** 云主机当机房出口、自己的宽带当实验用住宅、公司已有的专线。优点是来源清楚、账算得清。缺点是规模小、被单个目标封段后没有「下一个网段」。拨号、多卡路由器只在**线路是你的、合同允许**时才谈；拿来路不明的「猫池」当教材，本书不写。

**采购。** 看三件事：地址类型是否名实相符（抽检 ASN）、计费是按流量、按 IP 还是按成功请求、失败是否退款或换段。把抽检写成例行，而不是信任首页上的「住宅」二字。常见官网和产品名怎么对上 4.1 节，见下一节。

**成本。** 机房通常按台或按带宽；住宅/移动常按 GB 或按会话，浏览器一开，流量和时长一起涨。第 2.6 节的 cost per action 在这里落地：同一任务，直连、机房粘性、住宅轮换，单价可以差一个数量级。第 5.4 节会把预算做成按域名的降级，而不是全局开最贵的池。

**合规。**

- 只把出口用在你有权访问的目标上。
- 不采购、不接入来源无法说明的「海量家宽」。
- 供应商合同、日志留存、是否允许再分发流量，上线前和法务过一遍（附录 D）。
- 出口解决的是路由和容量，不是绕过授权。对方要登录或要开发者协议，换 IP 不能代替授权。

## 4.5 市面上的供应商怎么看

名单会过期，品牌会更名、关停或被查。下面是 **2026 年 8 月** 仍能公开打开的官网对照，用来把销售页上的名字对回 4.1 节，**不是推荐榜**。网上「2026 最佳代理」多数带分销链接，池规模和成功率以供应商自报为多，采购仍以合同、抽检 ASN、打你自己的授权目标为准。

**先对产品名，再看品牌。** 国内常见 SKU 和国际站不是同一套词：

| 销售页上的叫法 | 更接近 4.1 / 4.2 的哪一类 |
|----------------|---------------------------|
| 隧道 / 云端自动换 IP | 轮换出口；会话窗口由供应商参数决定 |
| 私密 / 短效 / 按条提取 | 存活几分钟到几十分钟的轮换；国内不少是拨号或机房段，不要默认当成住宅 |
| 独享 / 长效 / 静态 | 粘性或固定 IP，按月或按条 |
| Datacenter / 机房 | 4.1 的机房 |
| Residential rotating | 轮换住宅 |
| ISP / static residential | 4.1 的 ISP / 静态住宅 |
| Mobile | 4.1 的移动 |

青果等国内文档会写短效池基于**拨号 VPS**。这和「用户知情共享家宽」不是一回事，和「设备被 SDK 收编」更不是一回事。对不上来源说明的，按 4.4 节排除。

**国际站（企业与自助，产品线通常覆盖机房 + 住宅，部分有 ISP / 移动）：**

| 供应商 | 官网 | 怎么读 |
|--------|------|--------|
| Bright Data（原 Luminati） | [brightdata.com](https://brightdata.com/)、中文站 [bright.cn](https://www.bright.cn/) | 企业全栈：代理之外还有抓取 API、浏览器类产品。贵，合同和合规材料相对齐全。 |
| Oxylabs | [oxylabs.io](https://oxylabs.io/) | 同类企业档，文档和 SLA 常见于采购清单。 |
| Decodo（2025 年由 Smartproxy 更名） | [decodo.com](https://decodo.com/)、[decodo.cn](https://decodo.cn/) | 中端自助常见入口。官方声明只认这两个域名；`smartproxy.org`、`smartproxy.cn` 等是假冒站。 |
| Webshare | [webshare.io](https://www.webshare.io/) | 便宜机房和入门套餐谈得多，适合先验证「机房够不够」，不够再升级类型。 |
| IPRoyal | [iproyal.com](https://iproyal.com/) | 住宅按需付费常见；同样要抽检类型是否名实相符。 |
| SOAX | [soax.com](https://soax.com/) | 住宅 / 移动 / ISP，偏国家、城市、运营商筛选。 |

**国内站（隧道、短效、独享谈得多；海外住宅另售）：**

| 供应商 | 官网 | 怎么读 |
|--------|------|--------|
| 快代理 | [kuaidaili.com](https://www.kuaidaili.com/) | 国内爬虫圈出现最久的之一：隧道、私密/短效、独享，以及海外静态 / 动态。看增值电信等资质和合同，不看书评区金句。 |
| 青果网络 | [qg.net](https://www.qg.net/) | 短效、隧道、长效、独享；产品说明里对拨号 / 中转池写得比较直。 |

同档还有不少短效池品牌，换得快、广告密，本书不逐一罗列。免费公开代理列表（各种 free proxy list）不当出口：被滥用、不稳定，还可能是蜜罐。

**价格只记数量级。** 机房按 IP 或按流量，通常比住宅低一个数量级以上。国际住宅常见按 GB 计，公开套餐大致在「数美元 / GB」到企业折扣之间，最低承诺和流量过期会让账单变形。国内短效常按提取条数或通道。浏览器一开，流量和时长一起涨。要比的是打到**你有权访问的目标**时，每个成功动作的成本（第 2.6 节），不是首页大字。

**国内采购还要多问两句。**

- 供应商是否说得清资质、开票、日志留存；海外出口从哪条网络发出。部分厂商写明：海外代理需在大陆以外的网络环境使用——这和「从境内搭一条未许可的国际信道」不是同一件事，后者不要做。
- 旧教程里的**芝麻代理**（及品易 / 太阳 / 极光等芝麻系）已在 2024 年前后退出；**阿布云**官网 2026 年 2 月起停止新用户注册。不要按过期域名或转卖号付款。

**明确不要买。**

- 来源写成「海量真实家宽 / 闲置带宽共享」，却给不出用户知情同意和合同的。PacketStream 一类 P2P 分享模式，法律和声誉风险由你自己承担，本书不列入采购。
- **IPIDEA**（及公开报道中的 922 Proxy、360 Proxy 等相关品牌）：2026 年 1 月 Google Threat Intelligence 指其住宅网大量来自被 SDK / 预装软件收编、用户不知情的设备，并联合干扰其基础设施。池子大、单价低，不能代替来源合法。
- 声称「防封、过验证、打任何站点」的，把出口卖成对抗工具。出口解决路由和容量，不解决授权（第 1.3、1.5 节）。

试用只打**自建靶场或书面授权目标**：看连通、延迟、出口 IP 的 ASN 是否和宣传一致、粘性窗口是否守约。第 5 章再把抽检收进池的健康检查。不要拿未授权的商业站当「哪家更防封」的评测场。

出门考（仍用自建靶场最合适）：

1. 为三种任务各写一行选型——「直连 / 机房粘性 / 不该上代理」，并说明为什么。不必真的去买住宅网。
2. 打开上表任意两家官网，把他们的一个 SKU 对回 4.1 / 4.2 的类型；写一句你还缺哪份来源或合同材料才能采购。
