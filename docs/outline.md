# 目录

初稿已锁定。基础约 15–20%，进阶约 80%。有基础的读者可把第 3 章当自检清单，从第二部分读起。

实验默认用自建靶场、自有 Demo App 与授权测试账号。本书不写商业加固脱壳步骤、接码/养号操作、未授权群控刷量。
